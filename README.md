## Sobre o projeto

Este repositório apresenta o resultado do projeto prático de aprendizagem ativa proposto pela DIO.

O projeto foi desenvolvido a partir do caderno temático criado no NotebookLM, chamado:

> Mastering CompTIA Security+: A First-Attempt Success Strategy

O objetivo foi utilizar Inteligência Artificial como ferramenta de apoio ao estudo da certificação CompTIA Security+ SY0-701, combinando:

- Curadoria de fontes confiáveis;
- Organização estruturada do conhecimento;
- Engenharia de prompts;
- Análise crítica das respostas geradas;
- Identificação de dificuldades durante o processo de estudo;
- Criação de um miniguia reutilizável para futuras revisões.

> Este material tem finalidade educacional e não substitui a documentação oficial da CompTIA nem os materiais oficiais de preparação para o exame.

## Contexto e objetivos

A certificação CompTIA Security+ aborda fundamentos importantes de cibersegurança, como conceitos gerais de segurança, ameaças, vulnerabilidades, arquitetura, operações de segurança, gerenciamento de riscos e governança.

O caderno temático foi criado para transformar diferentes fontes de estudo em um material organizado, objetivo e orientado à preparação para o exame.

### Objetivo geral

Criar uma estratégia de estudos estruturada para compreender os principais conceitos da CompTIA Security+ e aumentar a preparação para realizar o exame na primeira tentativa.

### Objetivos específicos

- Compreender os principais domínios da certificação Security+;
- Relacionar conceitos teóricos a cenários práticos;
- Diferenciar ameaças, vulnerabilidades, riscos e controles;
- Revisar conceitos de identidade, acesso, criptografia e segurança de redes;
- Entender processos de resposta a incidentes;
- Criar uma rotina de revisão baseada em perguntas e recuperação ativa;
- Utilizar o NotebookLM para comparar, resumir e revisar fontes;
- Identificar lacunas de conhecimento durante os estudos;
- Criar prompts reutilizáveis para futuras sessões de aprendizagem.
